## Resolve corrections by scope and time

- The later prohibition on unsolicited editor switching supersedes "always
  open the next file". Explicitly requesting a new file still creates one.
- The brief experiment relaxing P04–P12 opening composition was rejected.
  Preserve the current source prompt; do not revive the discarded rewrite.
- Detailed generation prompts and minimal Element imports are different
  artifacts. "Keep the detail" is not authority to fill the import with scenes.
- Read-only MCP checks are part of the accepted film workflow. Application QA
  browser handoff restrictions are not a reason to refuse an Element lookup.
- A new image or UUID can coexist with an unchanged textual handle. The user
  already rebinding it is evidence, not a request to repeat the same action.

## Recover again only when needed

When history is explicitly requested, search both active and archived logs and
follow segment metadata and timestamps, not just the visible thread title.
Separate real user messages from injected skill catalogs, quoted documents,
compaction summaries and approval transcripts. Find later corrections before
promoting an old decision. Report missing segments or unreviewed evidence
honestly; do not claim a full review after reading only a summary.

For ordinary continuation, use this guide and the current production files;
do not reread the whole archive every turn. Keep raw extracts local and outside
the repository. Update these scoped lessons rather than appending a second
conversation diary or copying them into the manual-QA trust route.
