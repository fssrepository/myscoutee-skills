# MyScoutee template agent instructions

Scope: this repository and its frontend, nginx and MCP submodules. An in-scope
defect report authorizes diagnosis, repair and verification; respect an explicit
diagnosis-only or no-edit instruction.

Read and apply [shared development rules](../myscoutee-development.md) before
engineering work. Preserve the template's existing implementation and independent
deployment configuration; inspect its own frontend and scripts before editing.

For application QA, read [manual QA rules](../manual-qa.md) and use this project's
versioned launcher and explicit checklist. Backend campaign checkpoints and film
production assets belong to `myscoutee-backend`; they are not template fixtures.
The [trust library](../../.agents/trust/kernel.md) contains backend-specific
reference examples. Inspect the equivalent template implementation when applying
a matching card, and report a missing reference rather than creating one.
